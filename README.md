本项目旨在爬取地震历史数据，用于后续的地震趋势分析与预测建模。项目小组合作中，本人负责数据获取模块。  



| Field | Description |
|-------|-------------|
| 序号 | Record index |
| 列表项文本 | Earthquake title from list page |
| 时间 | Occurrence time |
| 经纬度 | Latitude and longitude |
| 震源深度 | Focal depth |
| 级数 | Magnitude |

-爬取工具：Selenium  
-浏览器驱动：ChromeDriver  
-数据处理：Pandas  
-存储格式：Excel
